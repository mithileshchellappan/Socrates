# Modules

All logic lives in local packages under `Packages/`. The app target (`App/`) is views and wiring only. Every package targets macOS 26 + iOS 26, Swift 6 language mode (complete concurrency checking, nonisolated by default). No automated test suite at present; verified by building and rendering (UI off screen with `tools/ParityRender`).
